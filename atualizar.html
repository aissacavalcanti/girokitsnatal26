Para atualizar o site:

  1. Descompacte o .zip baixado.
  2. No GitHub, abra o repositório trackingBW e clique em Add file → Upload files.
  3. Arraste todos os arquivos da pasta descompactada (inclusive base_vendas.json, que guarda o histórico para a próxima atualização).
  4. Clique em Commit changes. Em 1 a 2 minutos o link já mostra os dados novos.

O arquivo do Teams é o mesmo dashboard com os dados dentro, para quem abre sem internet.

O que esta página não faz (peça ao Claude quando precisar): incluir itens novos na tabela BW ou novos códigos de versão, mudar datas de vigência, gerar as planilhas em Excel e a sugestão de transferência, e atualizar o dashboard dentro do Claude.
